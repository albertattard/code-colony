Remote Engineer Briefing

Code Colony

The colony has gone silent. From a central station with only partial systems restored, you will reconnect to dormant CORE maintenance robots and bring the colony back online.

First Assignment

Start with one small mission: establish a control link to a docked CORE unit.

Introduction

You are the remote engineer for the recovery effort. Your job is to restore damaged systems, direct CORE maintenance units, and uncover what caused the colony to fail.

How Missions Work

  • Read the mission objective.
  • Enter a small Java command in the browser.
  • Click Run to execute it.
  • Watch the result and adjust your code if needed.

You do not need an IDE or local Java setup. The game provides the coding surface for you.

Mission 01

The first mission is intentionally small. You will bring a docked CORE online with one simple method call, then use later missions to give that CORE more detailed instructions.
