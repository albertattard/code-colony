# Mission 01: Wake The CORE

## Summary
Standby power is active in Maintenance Room A1. Re-establish a control link and bring the docked CORE online.

## Objective
Call `CORE.connect();` to bring CORE-01 online.

## Briefing
Standby power has returned to Maintenance Room A1, where a dormant CORE unit remains docked and unresponsive. Its exact condition is still unknown because no control link has been established. The only way to communicate with the unit is by issuing Java commands through the terminal. Connect to the CORE by calling `CORE.connect();` so you can assess its status and begin restoring it to operation.
