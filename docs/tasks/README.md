# Tasks

This directory contains project task documents.

Tasks are organized by status:

- `backlog/` for planned work
- `in-progress/` for active work
- `done/` for completed work kept for history

Task files should:

- describe a concrete unit of work
- link to the relevant specs and ADRs when applicable
- be updated as work progresses
